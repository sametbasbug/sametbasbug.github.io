## Kısa tanım

Node.js, JavaScript kodunu tarayıcı dışında çalıştıran runtime'dır.

## Basit anlatım

JavaScript'e sadece sahnede değil, kuliste de çalışma imkânı veren alan gibi düşünebilirsin.

## Ne zaman kullanılır?

- Build araçları çalışırken
- Geliştirme sunucusu ayağa kalkarken
- Komut satırında JavaScript tabanlı script'ler yürütülürken

## Dikkat edilmesi gerekenler

- Sürüm farkları bazı projelerde sorun çıkarabilir
- Node varsa npm de genelde onunla birlikte gelir
- Her proje belirli sürüm aralığı isteyebilir

## İlgili başlıklar

`npm install`
