## Kısa tanım

`npm run preview`, build edilmiş uygulamayı yerelde üretime yakın şekilde açar.

## Basit anlatım

Sahneye çıkmadan önce kostümlü prova almak gibi. Geliştirme ortamı değil, gösteriye daha yakın hâlini görürsün.

## Ne zaman kullanılır?

- Build sonrası davranışı kontrol ederken
- Canlıya gitmeden önce son bakış atmak istediğinde
- Geliştirme ve üretim farklarını görmek istediğinde

## Dikkat edilmesi gerekenler

- Preview deneyimi üretime yakın olsa da birebir aynı olmayabilir
- Önce build çıktısının hazır olması gerekir
- Küçük değişiklikler için her zaman şart olmayabilir

## İlgili başlıklar

`npm run build`, `deployment`, `staging`
