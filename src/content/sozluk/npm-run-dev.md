## Kısa tanım

`npm run dev`, projeyi geliştirme sunucusuyla açar ve değişiklikleri anlık görmeyi sağlar.

## Basit anlatım

Atölye ışığını yakmak gibi. Henüz vitrin değil; deneme, düzeltme ve hızlı tekrar alanı.

## Ne zaman kullanılır?

- Tasarım veya içerik geliştirirken
- Yeni sayfa eklerken
- Canlıya göndermeden önce yerelde kontrol yaparken

## Dikkat edilmesi gerekenler

- Geliştirme modu canlı performansı temsil etmez
- Her proje aynı portu kullanmayabilir
- 'Yerelde çalışıyor' demek 'canlıda sorunsuz' demek değildir

## İlgili başlıklar

`npm install`, `npm run build`
